# Personal Portfolio Website

A modern, responsive portfolio website built with **HTML, CSS, JavaScript, and React.js** to showcase my projects, skills, and professional journey.

## 🚀 Features
- Fully responsive design for desktop, tablet, and mobile
- Smooth navigation with React Router
- Interactive project showcase with live demo links
- Contact form for direct communication
- Clean, minimal UI with modern styling

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
- **Deployment:** GitHub Pages
- **Tools:** VS Code, Git, GitHub

## 📂 Sections
- **Home:** Introduction and personal branding
- **About:** Background, skills, and career goals
- **Projects:** Highlighted projects with GitHub + live demo links
- **Contact:** Easy way to reach me via form or social links
